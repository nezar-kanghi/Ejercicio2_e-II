Este ejercicio pide realizar un programa que permita insertar un nuevo ciclista, Actualizar un ciclista ya existente y eliminar un ciclista.
Primero se realizara un menu mediante Do-While y Switch, en el case 1 se realizara la insercion de datos, primero pedimos los datos por consola al usuario (nombre, nacionalidad, edad y id_equipo) la ID_CICLISTA se genera mediante una consulta MAX(ID_CICLISTA) y luego sumandole + 1, asi nos aseguramos que no se repiten, una vez tengamos todo esto realizamos una sentencia INSERT INTO y añadimos los datos. Luego en el case 2 se realizara la actualizacion de un ciclista ya existente pediremos al usuario que nos de la edad que quiere actualizar y luego a que ciclista quieres cambiarselo, una vez lo tengamos añadimos esos datos a una sentencia UPDATE CICLISTA. Por ultimo el case 3 sera la eliminacion de datos, comenzamos pidiendo el ID que se desea eliminar, realizamos un SELECT COUNT(*) FROM CICLISTA WHERE ID = ? para comprobar si el valor es payor a 0 entonces existe, si existe se realizara la sentencia DELETE FROM PARTICIPACION primero y luego se realizara DELETE FROM CICLISTA.
